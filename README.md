# YOLO工作台

一套**中文桌面端的 YOLO 全流程工作台** —— 数据集 → 标注 → 训练 → 检测，一条龙。
界面用 tkinter 写，一键启动，不需要敲命令。

> **版本**：见 `config.yaml` 的 `app.version`
> **运行要求**：Python 3.11+（推荐 3.13；标注工具 X-AnyLabeling 官方约束 >= 3.11）
> **许可**：**GNU AGPL-3.0**（见 `LICENSE`）｜ 第三方组件与依赖许可见 `NOTICE.md`

## 这是什么

不是又一个「ultralytics 的壳」。本工作台把一条完整链路做进了同一个窗口：

| 页面 | 做什么 |
|---|---|
| **检测** | 摄像头 / 视频 / 图片 / 桌面窗口 四种源实时推理；可录制、可切换模型 |
| **数据集与标注** | 导入 / 划分 / 体检数据集；**内置标注编辑器**（双击缩略图进入），支持自动标注 |

### 内置标注编辑器

双击「样本预览」里的任一缩略图即可进入。三栏式布局：左侧工具箱、中央画布、右侧对象列表。

| 键 | 工具 | 键 | 工具 |
|---|---|---|---|
| `V` | 选择（拖动 / 把手缩放） | `K` | 关键点（14 个身体部位） |
| `R` | 矩形框（HBB） | `.` | 自由点 |
| `O` | 旋转框（OBB） | `L` | 线段 |
| `P` | 多边形（seg） | `C` | 圆 |

`Ctrl+Z` 撤销 / `Ctrl+Y` 重做 / `Del` 删除 / `Ctrl+D` 复制 / `Ctrl+S` 保存 / `Esc` 关闭。
另有两个本地 AI 辅助：**本地重标**（pose→seg→SAM2 全量重标）与 **收框**（把框/多边形夹进关键点范围，防背景抢框）。
保存写回 YOLO `labels/*.txt`，类名取自数据集的 `data.yaml`。

| **模型训练** | ultralytics 封装，带训练预设、实时进度与指标曲线 |
| **环境配置** | 一键检测依赖 / CUDA / 磁盘；一键安装依赖；环境自检与自动修复 |
| **设置** | 主题（浅色 / 深色 / 跟随系统）、路径、模型库管理 |

**自动标注引擎链**（本地，零 API 调用）：
`yolo11n-pose`（人框 + 14 关键点）→ `yolo11s-seg`（像素掩码）→ `SAM2.1`（框提示精修）
→ 关键点夹紧（防关键点抢到框外）。

## 快速开始

```bash
# 1) 装依赖（会自动在官方源 → 清华 → 阿里之间回退）
双击 YOLO工作台.bat → 选 2) 安装依赖

# 2) 启动
#   双击 YOLO工作台.bat → 选 1) 启动工作台（自动挑 Python 3.13/3.12/3.11）
py -3.13 YOLO工作台.py
```

第一次用建议先点 **环境配置** 页跑一次自检。

### 跑自检前先装依赖（重要）

```bash
# 装完 requirements 再跑自检，否则会看到假失败
python -m pip install -r requirements.txt
python tools/qc/run_all_fitness.py
```

> ⚠️ 自检需要 `mss` / `tkinter`。**用没装依赖的裸解释器跑，会显示 SKIP 而不是通过**
> —— 那是「环境未就绪」，不是仓库坏了。缺依赖时自检会直接告诉你该装什么。
> 只有 `mss`/`tkinter` 都在、自检仍报 FAIL，才是真问题。

**退出码有三档**（`0` 全绿 / `1` 架构漂移 / `2` 判据失效 / `3` SKIP），
在册判据清单与读法见 **`tools/qc/SMOKES.md`**。想往这套体系里加东西，
**先读那一页** —— 里面有必须遵守的四条纪律。

## 数据集格式

标准 YOLO 结构，工作台按这个约定扫描 `data/datasets/*/`：

```
data/datasets/<名称>/
  data.yaml        # path / train / val / test / nc / names
  train/  valid/  test/
    images/  labels/
```

标签支持 **框 · 关键点（pose）· 多边形（seg）**；类别顺序由 `data.yaml` 的 `names` 决定。

> 本仓库**不含示例数据集**（体积与再分发许可考虑）——按上面的目录结构放入你自己的
> 数据集即可被扫描；仓库根目录自带的 `yolo11n*.pt` 等权重可直接用于**检测**页开箱体验。
